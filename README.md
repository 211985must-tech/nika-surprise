# Для Ники

Статическая романтическая страница на русском языке.

## Музыка

Положи свой легально полученный файл песни Ed Sheeran - Photograph сюда:

```text
assets/photograph.mp3
```

После первого клика браузер попробует включить музыку. Автовоспроизведение без действия пользователя большинство браузеров блокирует, поэтому страница специально начинается с кнопки.

## Как отправить

Самый простой вариант: отправить папку `nika-surprise` архивом или загрузить содержимое папки на GitHub Pages / Vercel / Netlify. Главный файл: `index.html`.
